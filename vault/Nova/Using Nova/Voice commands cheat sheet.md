# Voice commands cheat sheet

Say **"Nova, ..."** (the name near the start or end). After a reply, you get 6 s for one more request without the name.

## Basics
| Say | Does |
|---|---|
| "Nova" | "Yes, sir?" |
| "Stop" / "cancel" / "never mind" / "undo that" | stops, or undoes the last action |
| "No, I meant Steam" | corrects the last request |
| "Nova, stand down" / "Nova, wake up" | kill switch / back on |
| "Who are you?" / "what can you do?" | instant answers |

## PC
| Say | Does |
|---|---|
| "Open Spotify / Steam / GTA / Xbox" | opens apps and games, checked |
| "Close Spotify" / "quit Spotify" | close (says if it's still in the tray) / quit completely |
| "Switch to Chrome" / "minimise Discord" / "show the desktop" / "go back to the game" | windows |
| "Snap Firefox to the left" / "put Discord on the right" | half screen |
| "Move Spotify to my other screen" / "to screen 2" | other monitor |
| "Put Spotify and Discord side by side" | side by side ("undo that" puts them back) |
| "Volume 30" / "turn it down a bit" / "mute" | volume |
| "Brightness up" / "set brightness to 60" | laptop screen |
| "How's my PC doing?" / "how hot is my GPU?" | status |
| "Lock my PC" / "put the PC to sleep" / "restart" / "shut down" | power (asks first) |
| "Empty the recycle bin" | asks first; never from the phone |

## Browser and apps
| Say | Does |
|---|---|
| "Open a new tab" / "open YouTube in a new tab" / "go to the Spotify tab" / "close the YouTube tab" / "tab 3" / "reopen the last tab" | your Firefox, checked |
| "Click Subscribe" / "click the search box" | clicks by name |
| "Click send in Discord" / "in Spotify click shuffle" | any app |
| "Show numbers" ... "click 7" | numbers on everything clickable |
| "Show the grid" ... "click 14" / "zoom 14" / "scroll down" | voice mouse |
| "Type hello there" / "press enter" / "press control c" | keyboard |
| "Start dictation" ... "new line" / "scratch that" / "stop dictation" | dictation |
| "Summarise this page" / "what's this video about?" | Claude reads the page |

## Media
| Say | Does |
|---|---|
| "Pause" / "resume" / "skip" / "go back" | anything playing |
| "Play some Drake" / "play my liked songs" / "queue Hotline Bling" / "shuffle on" / "what's playing?" / "repeat this song" | Spotify |
| "Full screen the video and press play" / "skip the ad" / "skip ahead 30 seconds" | browser video |
| "Play MrBeast on YouTube" | YouTube results |

## Screen
| Say | Does |
|---|---|
| "What's on my screen?" / "read the error on my screen" | looks |
| (error box appears) "fix it" / "what does it say?" / "ignore it" | screen watch |
| (app freezes) "close it" | ends the frozen app |
| "Fix this error" | Claude looks and fixes |

## Claude and big jobs
| Say | Does |
|---|---|
| "Ask Claude ..." | answers from Claude |
| "Work it out" / "figure it out" / "use Claude to ..." / "Claude, ..." | Claude does it with Nova's tools |
| "Complete this assignment for me" / "do my homework" / "fill out this survey" / "do what's on my screen" (+ ", don't submit it") | background job |
| "How's it going?" / "how far?" / "stop working" / "also make sure..." | while a job runs |
| "Shorten the answers" / "rewrite them simpler" | follow-up to a finished job |
